## 用户图片完整重建

用户提供的 JPG：1152×1536。在原生 Android PhotoEngine 中按内置档案输出 4284×5712，共 24,470,208 像素；输入原文件 SHA-256 前后一致。

算法：Lanczos-3 线性光重建 + 轻度细节增强，JPEG 质量 98，sRGB SDR；此完整大图检查没有开启 AI。

输出：4,442,306 bytes；SHA-256：

`206737961ea806b9a1084176bf8c3a21733e0a7cb925cf0148d51eafae97816a`
